Vectr

A desktop-first vector design tool that feels like a modern Illustrator - and exports its layer tree as readable React components styled with Tailwind.

Source Roadmap What works Progress

What it is

A drawing application built the way a design tool should be: a document model with exact inverses, one validated command for every action, tools as state machines, and an interface that follows Illustrator where muscle memory matters.

  • Twelve tools as state machines: selection, direct selection, lasso, seven shapes, type, hand, zoom.
  • Real transforms: move, scale in the object's own frame, rotate with Shift snapping, Alt-drag to duplicate.
  • Paint: fills, strokes with caps, joins, dashes and alignment, linear and radial gradients with eight stops, all sixteen blend modes, named CMYK and spot swatches.
  • Pages: artboards with presets, rulers, a grid, and guides that snap and save with the document.
  • Documents: a versioned native format, autosave, crash recovery, and byte-stable saves.
  • An honest interface: no dead controls, and a packaged run of 145 steps as evidence.

Where it is going

The differentiator is the compiler: a layered Vectr document becomes a component tree a developer would keep. Before it, the remaining Illustrator parity work is scheduled in public - Bezier paths and booleans, full type, appearance and effects, file interchange, and the core parity gate.

  1. Phase 5 Path model, pen, booleans, width profiles
  2. Phase 6 Type: area, path, threading, styles
  3. Phase 7 Appearance stacks, effects, brushes and symbols
  4. Phase 8 SVG, PDF, and Illustrator interchange
  5. Phase 9 Core parity gate: platforms, performance, accessibility
  6. Phase 10 The React and Tailwind compiler

Built in the open

Every slice ships with typecheck, the full unit suite, a production build, packaged evidence, and a self-review on its pull request. The decisions record says why things are the way they are, including what is deliberately not built yet.
